# Telenor 통신비 기안 작성 도구

Telenor Connexion 통신비 invoice(PDF)를 올리면, 사내 결제요청서(기안서)
**본문**에 그대로 복사·붙여넣기할 표를 자동으로 만들어 주는 도구입니다.

## 폴더 구성
- `Telenor_통신비_기안생성기.html` — 실제 도구 (더블클릭해서 브라우저로 열기)
- `참고_파싱규칙_및_번역사전.md` — 파싱/번역 규칙, 샘플 데이터 정리 (참고용)

## 사용법
1. `Telenor_통신비_기안생성기.html` 을 **더블클릭**해서 브라우저(크롬 권장)로 엽니다.
2. **① Telenor invoice PDF**를 끌어다 놓거나 클릭해서 선택합니다.
3. **② 추출 결과 확인** — Invoice No·기간·항목이 자동 표로 채워집니다.
   틀린 부분은 그 자리에서 수정하고, `+ 행 추가` / `×`(삭제)로 항목을 조정할 수 있습니다.
   - ⚠ **라인합 ≠ invoice 총액** 경고가 뜨면 놓친 항목이 있다는 뜻이니 확인하세요.
4. **③ 환율(USD→KRW)** 입력 — `실시간 참고환율 불러오기` 버튼 또는
   `smbs 매매기준율`을 열어 직접 입력합니다. (실제 카드 청구 원화는 결제 후 확정)
5. **④ 본문 전체 복사** 버튼 → 기안서 본문에 **Ctrl+V**.

## 특징
- 항목(행) 개수 제한 없음 — invoice에 있는 만큼 자동으로 표시.
- 영문 항목 → 한국어 자동 번역 (사전에 없는 항목은 원문 유지).
- `합계` 라벨은 No.+항목 칸에 병합, 수량·총액 합계 자동 계산.
- VAT는 Reverse charge라 `VAT 없음` 자동 표기.

## 주의
- PDF 해석(pdf.js)과 실시간 환율에 **인터넷 연결**이 필요합니다.
- 제목·속성 필드(조직/직책 등)는 이전 기안 복사분을 그대로 쓰고,
  이 도구는 **본문(목적/내용/결제방법)만** 생성합니다.
- Telenor invoice 형식이 바뀌거나 새 항목이 나오면 번역/파싱 조정이 필요할 수 있습니다.
